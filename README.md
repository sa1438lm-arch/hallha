# حلّها — تحدي حل المسائل

لعبة تعليمية صفية تفاعلية Real-Time لطالبات الصف السادس الابتدائي  
**الدرس: خطة حل المسألة**

## التشغيل

```bash
npm install
npm start
```

يعمل على: `http://localhost:3000`

للدخول من أجهزة الفصل على نفس شبكة Wi-Fi:

```text
http://<IP-جهاز-المعلمة>:3000
```

## المميزات

- حتى **١٠ جلسات** مستقلة في نفس الوقت
- **٥ مجموعات** كحد أقصى لكل جلسة
- **٥ أسئلة** ثابتة من مجالات متنوعة
- مؤقت ٢٠ ثانية + نقاط حسب السرعة (حساب Server-Side)
- إعادة اتصال للمجموعات بعد Refresh
- أصوات على جهاز المعلمة فقط (`lobby.mp3` Loop، `start.mp3`، `winner.mp3`)
- تصميم عربي احترافي 2026 (Navy / Dark Purple)
- بدون قاعدة بيانات (تخزين مؤقت في الذاكرة)

## الأصوات

ضع ملفات الصوت في مجلد `/audio`:

- `lobby.mp3`
- `start.mp3`
- `winner.mp3`

يمكن استبدالها بأي ملفات بنفس الأسماء دون تعديل الكود.

## ملاحظات

- المعلمة تدير الجلسات من «إعدادات المعلم»
- المجموعات تنضم برمز الجلسة (٦ أرقام)
- لا تُرسل الإجابة الصحيحة للعميل أثناء السؤال
- عند إعادة تشغيل الخادم تُحذف الجلسات
